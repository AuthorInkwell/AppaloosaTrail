THE APPALOOSA TRAIL
A fan tribute to The Oregon Trail, set in Equestria.


HOW TO PLAY
-----------

Double-click:

    Play The Appaloosa Trail.bat

A small black window appears and the game opens in its own window. Keep the
black window open while you play; closing the game window shuts everything
down on its own.

That is the whole thing. Nothing is installed, nothing runs in the background
afterwards, and nothing touches the internet.


IF WINDOWS ASKS "ARE YOU SURE?"
-------------------------------

Windows sometimes warns about files that came from someone else. Choose
"More info" and then "Run anyway". You can also right-click the .bat file,
choose Properties, and tick "Unblock" at the bottom.


CONTROLS
--------

    number keys        pick a menu option
    arrow keys, ENTER  also pick a menu option
    SPACE BAR          continue; stops the wagon to size up the situation
    arrow keys         move and steer in the foraging and forest sequences
    ESC                back out of a screen
    M                  sound on and off
    F                  fullscreen


IF THE .BAT FILE DOES NOT WORK
------------------------------

Double-click this file, or drag it onto a browser window:

    game\index.html

The whole game is in that one file, so it plays perfectly well that way.
Saved journeys and the Hall of Fame still work. The only thing you lose is
drop-in music from the folder below.


ADDING YOUR OWN MUSIC
---------------------

Put a MIDI file in the "music" folder, named after the part of the game it
should play in, and restart the launcher. Choices are:

    title, store, travel, landmark, forage, river, everfree, victory, memorial

So "music\title.mid" replaces the title screen music. Files ending in .ogg,
.mp3 or .wav work too. The Sound and Music screen in the game lists whatever
it found.
